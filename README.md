# GatherVibe - Платформа для поиска компании на мероприятия

Проект по разработке веб-приложения для организации совместного посещения культурных и развлекательных мероприятий.

## 📋 О проекте

GatherVibe - это социальная платформа, которая помогает людям находить компанию для посещения мероприятий: концертов, выставок, фестивалей, мастер-классов и других событий.

### Основные возможности:
- 🔍 Поиск мероприятий по категориям и местоположению
- 👥 Создание групп для совместного посещения
- 💬 Встроенный чат для обсуждения деталей
- 👤 Система профилей с интересами и рейтингом
- 📅 Календарь событий и планировщик
